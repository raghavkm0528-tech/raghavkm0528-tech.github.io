# K Raghavendra — Embedded Software Developer Portfolio

Static responsive portfolio website with a black/purple theme and scroll animations.

## Preview on Ubuntu
```bash
cd ~/Desktop/Raghav/Personal/portfolio
python3 -m http.server 8000
```
Open http://localhost:8000 and use Ctrl+Shift+R to refresh after updates.

## Deploy for free
Upload `index.html`, `style.css`, and `script.js` to a public GitHub repository.
In Settings > Pages, select Deploy from a branch, main, /(root).
GitHub Pages will publish your static site.

## Notes
